# StoryDirector workflow

For successfully completed changes in this repository:

1. Implement the requested change and run the relevant tests.
2. Create a descriptive commit.
3. Integrate it into `develop` (a separate fix branch is optional).
4. Push `develop` to GitHub without asking again.
5. Report the commit hash, test results and a short summary.

Do not automatically modify or merge `main`. Never force-push. Preserve existing features and settings. If tests fail or a merge conflicts, stop and report the failure rather than forcing integration or publication.
